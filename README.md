# Razorpay UI Clone

A responsive frontend UI clone of the Razorpay website built for learning and practice purposes.
This project focuses on recreating a real-world payment platform interface using modern
utility-first CSS.

## Live Demo
https://sanchitaroradev.github.io/razorpay-clone-tailwind/

## Author
Sanchit Arora  
GitHub: https://github.com/sanchitaroradev

## Tech Stack
- HTML5
- Tailwind CSS
- PostCSS
- Vite (for local development)

## Features
- Pixel-perfect Razorpay landing page UI
- Fully responsive layout
- Custom Tailwind configuration
- Clean and structured codebase
- Utility-first styling approach

## Purpose
This project was created to:
- Practice Tailwind CSS in a real-world layout
- Improve frontend UI replication skills
- Understand responsive design using utility classes

## Disclaimer
This is a frontend UI clone created strictly for educational purposes.
No backend functionality or real payment processing is implemented.
All design credits belong to Razorpay.
